## 深入分析：jieba

**它解决什么子任务**：中文没有空格，计算机不知道“加微信领资料”该切成几个词。jieba 做的就是分词，把连续汉字切成词序列。

**输入输出**：
- 输入：字符串，例如 `"加微信wx12345领内部资料"`
- 输出：词列表，例如 `["加", "微信", "wx12345", "领", "内部", "资料"]`

**依赖与权限**：纯本地 Python 包，主要依赖自带词典；不调用外部服务，不需要网络权限。

**限制**：
- 网络新词、缩写、错别字容易切错
- 不同领域需要自定义词典才能切得准
- 本项目使用的是**英文短信数据集**，jieba 按空格/英文词切分能工作，但其中文词典优势无法体现；消融实验也确实显示单字切分在 TF-IDF 组上反而更高（见下）

**行为核验**：
1. 阅读 GitHub README，确认 `jieba.lcut()` 的返回类型。
2. 在终端试跑：`jieba.lcut('Free entry in 2 a wkly comp to win FA Cup')`，得到 `['Free', 'entry', 'in', '2', 'a', 'wkly', 'comp', 'to', 'win', 'FA', 'Cup']`，确认英文按词切分正常。
3. 在真实数据上做消融：TF-IDF 组有分词 Macro-F1 = **0.8586**，关闭 jieba 改单字切分后为 **0.9309**。组件与数据语言不匹配，实验结果如实记录。

**适配工作**：
- 写了 `make_tokenizer(use_jieba)`，让分词可以一键开关，方便消融实验
- 把分词函数接进 sklearn 的 `Pipeline`，保证训练和预测用同一套处理
- 过滤空白词，避免空字符串变成特征
- 输入校验（空输入、超长输入）在分词之前拦截

## 本项目编写的部分

- `src/agent.py`：Agent 流程、置信度闸门、异常处理、相似评论检索
- `src/train.py` / `src/evaluate.py`：实验流程编排、指标计算、消融实验设计、失败案例与低置信度候选自动生成
- `src/prepare_uci_data.py`：UCI 原始数据到项目 CSV 的转换、标签映射、去重
- 报告分析与结论
