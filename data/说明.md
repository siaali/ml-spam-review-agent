# 数据说明

## 数据来源

- **数据集**：UCI Machine Learning Repository — SMS Spam Collection
- **链接**：https://archive.ics.uci.edu/dataset/228/sms+spam+collection
- **DOI**：10.24432/C5CC84
- **许可证**：CC BY 4.0（署名 4.0 国际）
- **引用**：Almeida, T. & Hidalgo, J. (2011). SMS Spam Collection [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5CC84
- **原始规模**：5574 条带标签短信（ham 正常 / spam 垃圾）

## 本项目如何使用

本项目把公开短信数据集作为**垃圾短消息审核 Agent** 的训练与评估数据。原始短信来自：Grumbletext 论坛、NUS SMS Corpus、Caroline Tag 博士论文、SMS Spam Corpus v0.1 Big，均为公开或研究用途来源。

### 标签映射

| 原始标签 | 项目标签 | 含义 |
|---|---|---|
| `ham` | `normal` | 正常消息 |
| `spam` | `spam` | 垃圾/广告/诈骗消息 |

### 筛选与清洗规则

1. 原始文件每行格式为 `标签<TAB>短信正文`，按第一个制表符切分。
2. 合并连续空白字符、去掉首尾空白，**不改动短信正文内容**。
3. 去掉完全重复的短信，避免训练集和测试集出现同一条导致指标虚高。
4. 跳过空行或格式异常行（本次为 0 条）。
5. 转换脚本：`src/prepare_uci_data.py`，可复现上述全部步骤。

### 处理后规模

| 项目 | 数量 |
|---|---|
| 原始数据 | 5574 条 |
| 去除完全重复 | 414 条 |
| 最终保留 | **5160 条** |
| 其中 normal | 4518 条 |
| 其中 spam | 642 条 |

## 隐私与脱敏

- 数据集来自 UCI 公开仓库，原始来源已由数据集提供方做公开化处理。
- 本项目**未额外采集个人通信内容**，未引入姓名、手机号、学号等新的个人标识。
- 报告与代码中不展示可识别个人的原始元数据；实验样例仅引用短信文本本身。
- 若后续替换为自采评论数据，必须另行说明脱敏方式并取得相应授权。

## 数据划分

`src/evaluate.py` 使用 `train_test_split(test_size=0.2, random_state=42, stratify=labels)` 做分层随机划分：

- 训练集：4128 条（80%）
- 测试集：1032 条（20%）
- 划分随机种子：42

向量化器只在训练集上拟合，测试集不参与训练，避免数据泄漏。

## 局限（报告讨论部分要写）

- 该数据集为**英文短信**，而 Agent 演示包含中文输入；语言不一致是已知局限。
- 短信和课程论坛评论在长度、语气、广告形式上存在差异，结论不能直接外推到中文评论区。
- 垃圾类占比约 12.4%，存在类别不平衡，因此不能只看准确率，必须报告垃圾类 Precision / Recall / F1。
