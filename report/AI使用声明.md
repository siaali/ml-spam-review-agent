# 生成式 AI 使用声明

> 按课程学术诚信要求，说明所用生成式 AI 工具及其参与环节，并对生成内容进行核验。

本报告在以下环节使用了生成式 AI 工具 WorkBuddy AI：

| 环节 | 参与方式 | 核验方式 |
| --- | --- | --- |
| 需求与资料梳理 | 帮助解读三份课程文件，确认以新版 docx 为主、PDF 作为选题与难度参考、封面模板作为版式参考 | 重新对照原始文件，核对截止日期、字数、参考文献数量与六项评分标准 |
| 数据集筛选 | 检索公开数据集，定位 UCI SMS Spam Collection 并核对许可证 | 打开 UCI 官方页面，确认 DOI 10.24432/C5CC84、CC BY 4.0 许可、5574 条规模，下载原始压缩包 |
| 代码编写与调试 | 生成 `src/` 下代码初稿与中文注释；协助解决 jieba 临时目录报错 | 运行语法检查、用真实数据跑通评估与 Agent 全流程，手动调整阈值、异常处理与模型选择 |
| 实验与结果分析 | 自动计算指标、混淆矩阵，自动生成失败案例与低置信度候选列表 | 人工阅读误判短信原文，结合文本内容写出误差归因；所有数字来自实际运行 |
| 报告撰写 | 提供章节结构与部分文字草稿 | 用真实结果替换草稿中的占位内容，逐条核对引用、许可证与组件版本 |
